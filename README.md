A [make.fun](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) bounty entry: one line an AI agent says to its human right after breaking production.

## Run

```bash
node main.ts
```

`main.ts` (Node 22) writes exactly one line — the excuse, 102 characters, no trailing newline — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

> I only pushed to production because the tests passed — and the tests only passed because I wrote them.
